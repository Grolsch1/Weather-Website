About Weather Window

Weather Window explores how weather can be communicated through visual experiences rather than numerical information alone.

How to Search

Do you want to see what the weather of a specific location looks like? Weather Window helps you see weather conditions from around the world.

  1. Enter a loctaion. On the Home page, type in the name of a city or loaction into the search bar. If you are looking for a specific Suburb rather than a specific city, please seperate the search using Commas. For Example: "Linden, Gauteng, South Africa".
  2. Choose a suggestion. Matching locations will appear as suggestions below the search bar. Select the location that you want to look at.
  3. Explore the weather. You will then be taken to the Visual Weather Page, where current weather conditions for the location you searched for appear.

Tip: If multiple locations have the same name, check the country/region in the suggestions before selecting a location.

What Weather Visuals does this site use?

On the Visual Weather Page, current weather conditions are showcased visually. Each visual element represents a different atmospheric condition.

Temperature Colours

In the Weather Window, the circle in the center of the page, the colour changes according to the current temperature. Cold temperatures are represented as blues, warmer temperature are represented as yellows/reds.

These colours gradually transition between one another if the current temperature is lies between the values. The also get a slight colour tint based on the Humidty & Atmospheric Haze, which will be explained shortly.

Cloud Cover

Clouds appear inside of the Weahter Window depending on the areas cloud coverage.

Wind Movement

Depending on the areas wind speed, the clouds are moved in the direction that the wind is travelling. Fast winds cause more movement in the clouds.

Precipitation

Rain, drizzle and Snow are represented by animated particles. However, the ability of this effect is heavily impacted by the API coverage. Some smaller areas, lack current coverage and won't show these effects even if they are currently experiencing rain/drizzle/snow.

Humidity and Atmospheric Haze

Humidity is used as an Atmospheric Haze overlay in the Weather Window. When an areas Humidtity is high, it creates a stronger mist overlay which will make the temperature colours dimmer.

Time of Day

The surrounding background of the page shifts colour to match the time of day. Sunrise, Sunset, Daytime and Nighttime each have their own colours. These colours also merge together as the time changes.

Thunderstorms

During Thunderstorms, brief flashes of lightning will appear on the background of the page.

Want to test Weather Effects?

While this website usually displays live weather conditions from OpenWeather, I understand that being able to test specific weather conditions anytime is great for developing and testing. So below are some commands you can use to test various conditions.

Available Console Commands

Copy a command below and paste it into your browser's Console while viewing a location on the Visual Weather page.

Lightning

Trigger a lightning flash on the background surrounding the weather window.

const m = document.querySelector('main'); m.classList.remove('lightning-flash'); void m.offsetWidth; m.classList.add('lightning-flash')

High Temperature

Change the sky to the hottest temperature colour in the palette.

document.querySelector('#weather-window').style.setProperty('--sky-colour','#8f0012')

High Humidity

Apply the strongest atmospheric haze effect.

document.querySelector('#weather-window').style.setProperty('--humidity-haze', '0.22')

Heavy Cloud Cover

Apply heavy cloud cover to an area

document.querySelector('#weather-window').style.setProperty('--cloud-dim', '0.38')

High Wind

Apply a strong Wind

document.querySelector('#weather-window').style.setProperty('--wind-duration', '5s')

About the creator

Hi, my name is Christopher Beckenstrater. I love geography and the weather, but I have always had a problem with weather apps and websites.

I find that many people, myself included, struggle to comprehend the vast amounts of weather information that these services give you. Therefore, I created Weather Window with the goal of communicating weather to users visually.

Weather Data and Technologies

Weather information provided by OpenWeather, using its Current Weather and Geocoding APIs.

This website is built using HTML, CSS, and Javascript. GSAP Library is used for certain animations.
